¿Cómo funciona?

Panel pensado para que casi nunca tengas que tocar Google Sheets.
🔗 Sincronizar

Pega la URL /exec de tu Apps Script y pulsa Conectar. Se guarda en este navegador.

➕ Producto

Solo el código es obligatorio. Puedes dejar los demás campos vacíos.

🖼️ Imagen

Seleccionas una foto. Apps Script la sube a GitHub y devuelve el enlace público para la columna Imagen. El token NO va dentro de este HTML.

🔐 GitHub

En Apps Script configura GITHUB_TOKEN, GITHUB_OWNER, GITHUB_REPO y opcionalmente GITHUB_BRANCH/GITHUB_FOLDER en Propiedades del script.

⚠️ Repetidos

Si ID o código ya existe, aparecerá una advertencia. Puedes cancelar o marcar que deseas guardar el repetido.

✏️ Editar

Puedes cambiar cualquier dato mostrado por el panel y guardar los cambios.

🗑️ Borrar

Elimina el producto directamente de la fila correspondiente de Google Sheets.

💵 Dólar

El bloque de tasa solo modifica CONFIGURACION!B2 y renueva sus 24 horas de vigencia.

📑 Nuevas columnas

Si agregas una columna en la hoja, el panel la detectará y mostrará como campo adicional.
